# Проверка реализации

Проверено в Python 3.12, Linux, на полном реальном наборе Kaggle v13.

- 15 тестов pytest проходят: зарплатные периоды/валюты/ошибочные диапазоны,
  границы навыков, dedup между чанками, отсутствующие колонки, целостность БД,
  SQL-частоты, временные разрывы, отсутствие утечки в прогнозе,
  параметризованные фильтры, анализ без доступной зарплаты.
- Полный ETL: 123 849 входных и очищенных строк; 0 дубликатов ID,
  0 некорректных ID и 0 неразбираемых дат.
- Независимая проверка сравнила все 13 общих скалярных полей SQLite и Parquet
  на 123 849 строках: расхождений нет; foreign_key_check пуст.
- Все 10 SQL-запросов выполнены, результаты сохранены в reports/sql.
- Частоты навыков SQL и Pandas полностью совпадают.
- Streamlit AppTest: демо, фильтрация, пустое сочетание и отсутствие БД
  отображаются без исключений.
- Chromium/Playwright: полный дашборд загружен, 123 849 вакансий,
  графики отрисованы; скриншот reports/figures/dashboard.png.
- PDF с кириллицей сгенерирован и первая страница визуально проверена.
  PPTX создан библиотекой python-pptx (12 слайдов); рендер в PowerPoint
  в этой среде не проверялся.

В независимом ревью выявлены и исправлены два дефекта: NaN при отсутствии
USD-зарплат и повторное вычисление среднего роли для каждой строки в SQL №10.
Для первого добавлен регрессионный тест, подтверждённый падением до исправления.
Второй устранён предагрегацией по ролям в CTE.

Результаты производительности зависят от окружения. Точный воспроизводимый
состав пакетов сохранён в requirements-lock.txt. GitHub Actions настроен,
но его удалённый запуск возможен только после публикации репозитория.
